# The Word You'd Delete From the Dictionary

One word the entrant would erase from the dictionary forever: **deadline**.

Erase the word and nothing can ever be late again — no word for a due date means nothing can be overdue, nothing can be missed, and every agent and human alive is suddenly, permanently, on time. The joke is the gap the word leaves in the language.
